# DevHelper 浏览器开发助手插件

一个功能丰富的浏览器开发助手插件，为前端开发者提供多种实用工具，提升开发效率。

## 功能特性

- **JSON美化**：格式化和美化JSON数据，支持语法高亮
- **文件对比**：比较两个文件或文本内容的差异
- **正则公式速查**：常用正则表达式查询和测试
- **专业取色**：颜色选择器和颜色转换工具
- **Mock工具**：拦截浏览器请求并返回自定义的Mock数据

## 安装说明

1. 克隆或下载本仓库到本地
2. 打开Chrome浏览器，访问 `chrome://extensions/`
3. 启用右上角的「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择本仓库的根目录
6. 扩展安装成功后，浏览器工具栏会出现插件图标

## Mock工具使用指南

### 开启和使用Mock功能

1. **打开Mock工具**：
   - 点击浏览器右上角的插件图标，从弹出菜单中选择「Mock工具」
   - 或使用快捷键：Windows/Linux: `Ctrl+Shift+M`，Mac: `Command+Shift+M`

2. **启用Mock功能**：
   - 在Mock工具页面顶部，通过全局开关开启或关闭Mock功能
   - 开关为绿色时表示已开启，红色表示已关闭

3. **管理Mock规则**：
   - **添加规则**：点击「添加规则」按钮，填写规则信息
   - **编辑规则**：点击规则右侧的「编辑」按钮修改现有规则
   - **删除规则**：点击规则右侧的「删除」按钮删除规则
   - **批量操作**：支持批量删除、导出和导入规则

### Mock规则设置项

- **规则名称**：给规则取一个有意义的名称
- **API路径**：要拦截的请求URL路径
- **URL匹配类型**：
  - 包含：只要URL中包含指定字符串就会被拦截
  - 精确：URL必须完全匹配才会被拦截
  - 正则：使用正则表达式匹配URL
- **请求方法**：选择要拦截的HTTP方法（GET、POST、PUT、DELETE、PATCH等）
- **规则描述**：可选，添加规则的描述信息
- **是否启用**：控制单个规则的启用状态
- **响应内容**：设置要返回的Mock数据，必须是有效的JSON格式
- **响应时间**：可选，设置响应延迟时间（毫秒），模拟网络延迟

### 使用示例

1. **创建用户列表Mock规则**：
   - 规则名称：`用户列表数据`
   - API路径：`/api/users`
   - URL匹配类型：`包含`
   - 请求方法：`GET`
   - 响应内容：
   ```json
   {
     "code": 200,
     "message": "success",
     "data": [
       { "id": 1, "name": "张三", "age": 25 },
       { "id": 2, "name": "李四", "age": 30 }
     ]
   }
   ```

2. **当启用该规则后，所有匹配 `/api/users` 的GET请求都会返回上述Mock数据**

### 导入和导出规则

- **导出规则**：可以将当前所有Mock规则导出为JSON文件，方便备份或在其他环境中使用
- **导入规则**：可以从之前导出的JSON文件中导入规则，快速恢复设置

## 测试Mock功能

插件提供了一个测试页面 `mock_test.html`，可以用于验证Mock功能是否正常工作。使用方法：

1. 在浏览器中打开 `mock_test.html` 文件
2. 启用Mock工具并添加相关规则
3. 点击页面上的测试按钮，查看响应结果

## 技术栈

- Chrome扩展开发（manifest v3）
- Vue.js 3 + Element Plus（Mock工具界面）
- JavaScript

## 注意事项

1. Mock功能仅在启用状态下生效，关闭后不会拦截任何请求
2. 响应内容必须是有效的JSON格式，否则可能导致错误
3. 对于复杂的URL匹配，建议使用正则表达式类型
4. 在生产环境中使用前，请确保关闭Mock功能，避免影响正常业务
