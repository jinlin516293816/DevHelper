CSS 布局面试题 ​

1. Flexbox 布局 ​

问题：Flexbox 布局的主要特性是什么？ ​

答案：

Flexbox 是一种一维布局模型，主要特性包括：

  • 灵活的空间分配：可以自动分配容器内项目的空间
  • 方向控制：通过 flex-direction 控制主轴方向（row/column）
  • 对齐方式：通过 justify-content（主轴对齐）和 align-items（交叉轴对齐）控制项目对齐
  • 弹性伸缩：通过 flex-grow、flex-shrink 和 flex-basis 控制项目的伸缩行为
  • 响应式：可以轻松实现响应式布局

问题：如何使用 Flexbox 实现水平和垂直居中？ ​

答案：

css
.container {
  display: flex;
  justify-content: center; /* 水平居中 */
  align-items: center; /* 垂直居中 */
  height: 100vh;
}

2. Grid 布局 ​

问题：Grid 布局与 Flexbox 布局的区别是什么？ ​

答案：

  • 维度：Flexbox 是一维布局（处理行或列），Grid 是二维布局（同时处理行和列）
  • 控制粒度：Grid 提供更细粒度的布局控制，如行列大小、间距等
  • 适用场景：Flexbox 适合组件内部布局，Grid 适合整体页面布局
  • 浏览器支持：Flexbox 支持更好，Grid 是较新的特性

问题：如何使用 Grid 实现一个三列布局？ ​

答案：

css
.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr; /* 三列等宽 */
  gap: 20px; /* 列间距 */
}

3. 传统布局 ​

问题：浮动布局的优缺点是什么？ ​

答案：

优点：

  • 实现简单，浏览器支持好
  • 可以实现文字环绕效果

缺点：

  • 容易导致父元素高度塌陷
  • 需要清除浮动，增加代码复杂度
  • 不适合复杂的响应式布局

问题：如何清除浮动？ ​

答案：

  1. clear: both：在浮动元素后添加一个空元素，设置 clear: both
  2. overflow: hidden：给父元素设置 overflow: hidden
  3. 伪元素清除：使用 ::after 伪元素
css
.clearfix::after {
  content: '';
  display: table;
  clear: both;
}

4. 响应式布局 ​

问题：响应式布局的实现方式有哪些？ ​

答案：

  1. 媒体查询：使用 @media 规则根据屏幕尺寸应用不同的样式
  2. 弹性布局：使用 Flexbox 和 Grid 实现弹性布局
  3. 相对单位：使用 rem、em、% 等相对单位
  4. 图片响应式：使用 max-width: 100% 确保图片适应容器
  5. viewport 元标签：设置 meta name="viewport" 确保移动设备正确显示

问题：如何实现一个响应式的两列布局，在小屏幕上变为单列？ ​

答案：

css
.container {
  display: flex;
  flex-wrap: wrap;
}

.column {
  flex: 1;
  min-width: 300px;
}

/* 或者使用媒体查询 */
@media (max-width: 768px) {
  .container {
    flex-direction: column;
  }
}

.fixed {

  bottom: 20px;
  right: 20px;
}

/* 粘性定位 */
.sticky {
  position: sticky;
  top: 0;
  background: white;

2. 层叠上下文 ​

问题：什么是层叠上下文？什么是 z-index？ ​

答案：

层叠上下文是 HTML 元素的三维概念，每个元素都在 z 轴（垂直于屏幕）上有一个层叠顺序。层叠上下文可以由某些 CSS 属性创建。

z-index 只有在定位元素（position 不是 static）上才会生效，它控制元素在层叠上下文中的层叠顺序。

层叠顺序（从低到高）：

  1. 层叠上下文的 background 和 border
  2. z-index 为负值的层叠上下文（值越小越靠下）
  3. 普通流块级元素（未定位）
  4. 浮动元素（未定位）
  5. 普通流行内元素（未定位）
  6. z-index 为 0 或 auto 的层叠上下文
  7. z-index 为正值的层叠上下文（值越大越靠上）
css
/* 创建层叠上下文 */
.container {
  position: relative;
  z-index: 1; /* 创建层叠上下文 */
}

.item1 {
  position: absolute;
  z-index: 2; /* 比 item2 更靠上 */
}

.item2 {
  position: absolute;
  z-index: 1;
}

问题：如何创建层叠上下文？ ​

答案：

以下情况会创建层叠上下文：

  1. 根元素（html）
  2. position 为 absolute/relative/fixed/sticky，且 z-index 不是 auto
  3. flex 或 grid 容器的子元素，且 z-index 不是 auto
  4. opacity 小于 1 的元素
  5. transform、filter、perspective、clip-path、mask 等属性不为 none 的元素
  6. will-change 为以上属性的元素
  7. isolation 为 isolate 的元素

1. CSS 单位 ​

问题：px、em、rem、vw、vh 等单位的区别是什么？ ​

答案：

单位描述特点
px像素绝对单位，固定大小
em相对单位相对于父元素的 font-size
remroot em相对于根元素（html）的 font-size
vwviewport width相对于视口宽度，1vw = 视口宽度的 1%
vhviewport height相对于视口高度，1vh = 视口高度的 1%
vminviewport minimum相对于视口宽度和高度中的较小值
vmaxviewport maximum相对于视口宽度和高度中的较大值
%百分比相对于父元素的对应属性
css
/* px - 固定像素 */
.box {
  width: 200px;
  height: 200px;
}

/* em - 相对父元素 font-size */
.parent {
  font-size: 16px;
}

.child {
  font-size: 1.5em; /* 24px */
  padding: 1em; /* 16px（继承自 parent） */
}

/* rem - 相对根元素 font-size */
:root {
  font-size: 16px;
}

.item {
  font-size: 1.25rem; /* 20px */
}

/* vw/vh - 相对视口 */
.responsive {
  width: 50vw; /* 视口宽度的 50% */
  height: 100vh; /* 视口高度的 100% */
}

/* 百分比 - 相对父元素 */
.parent {
  width: 400px;
}

.child {
  width: 50%; /* 200px */
}

CSS 显示和隐藏 ​

1. 元素显示和隐藏 ​

问题：CSS 隐藏元素的方法有哪些？它们的区别是什么？ ​

答案：

方法是否占据空间能否点击说明
display: none否否完全移除，不占据空间，不参与渲染
visibility: hidden是否不可见，但占据空间
opacity: 0是是透明，但占据空间，可点击
width: 0; height: 0否否尺寸为 0，不占据空间
transform: scale(0)是否缩放为 0，占据空间，不可点击
clip-path: polygon(0 0)是否裁剪为 0，占据空间
position: absolute; left: -9999px否否移到屏幕外，不占据空间
css
/* display: none - 完全隐藏 */
.hidden1 {
  display: none;
}

/* visibility: hidden - 隐藏但占据空间 */
.hidden2 {
  visibility: hidden;
}

/* opacity: 0 - 透明但占据空间，可点击 */
.hidden3 {
  opacity: 0;
}

/* 移出屏幕外 */
.hidden4 {
  position: absolute;
  left: -9999px;
  top: -9999px;
}

CSS BFC ​

1. BFC 概念 ​

问题：什么是 BFC？BFC 有什么作用？ ​

答案：

**BFC（Block Formatting Context，块级格式化上下文）**是一个独立的渲染区域，BFC 内部的元素不会影响外部元素。

BFC 的作用：

  1. 清除浮动
  2. 防止外边距合并
  3. 阻止元素被浮动元素覆盖
  4. 包含浮动元素

问题：如何创建 BFC？ ​

答案：

以下情况会创建 BFC：

  1. 根元素（html）
  2. float 不为 none
  3. position 为 absolute 或 fixed
  4. display 为 inline-block、table-cell、table-caption、flex、inline-flex、grid、inline-grid
  5. overflow 不为 visible
  6. contain 为 layout、content、paint、strict
  7. display: flow-root（专门用于创建 BFC）
css
/* 创建 BFC 的常用方法 */
.bfc1 {
  overflow: hidden;
}

.bfc2 {
  display: flow-root; /* 推荐 */
}

.bfc3 {
  display: inline-block;
}

.bfc4 {
  float: left;
}

问题：BFC 如何解决外边距合并？ ​

答案：

当两个相邻元素都在同一个 BFC 中时，它们的垂直外边距会合并。可以将其中一个元素放在另一个 BFC 中来防止合并。

html
<!-- 外边距合并 -->

  <div class="box1" style="margin-bottom: 20px;"></div>
  <div class="box2" style="margin-top: 20px;"></div>
</div>
<!-- 实际间距只有 20px，不是 40px -->

<!-- 使用 BFC 防止外边距合并 -->
<div class="container">
  <div class="box1" style="margin-bottom: 20px;"></div>
  <div class="wrapper" style="overflow: hidden;"> <!-- 创建 BFC -->
    <div class="box2" style="margin-top: 20px;"></div>
  </div>
</div>
<!-- 现在间距是 40px -->

2. CSS 特殊性（优先级） ​

问题：CSS 优先级是如何计算的？ ​

答案：

CSS 优先级从高到低：

  1. !important - 最高优先级
  2. 内联样式 - style 属性（1000）
  3. ID 选择器 - #id（100）
  4. 类选择器、属性选择器、伪类选择器 - .class、[attr]、:hover（10）
  5. 元素选择器、伪元素选择器 - div、::before（1）
  6. 通配符选择器 - *（0）

注意：

  • 同级选择器中，后面的会覆盖前面的
  • 内联样式无法被外部样式覆盖，除非使用 !important
  • !important 会覆盖内联样式
css
/* 优先级示例 */
/* 100 + 10 = 110 */
#id .class {
  color: red;
}

/* 10 + 10 = 20 */
.class:hover {
  color: blue;
}

/* 1 + 1 = 2 */
div p {
  color: green;
}

2. animation 关键帧动画 ​

问题：animation 和 transition 的区别是什么？ ​

答案：

3. 动画性能优化 ​

问题：如何优化 CSS 动画性能？ ​

答案：

  • 使用 transform 和 opacity：这两个属性不会触发重排（reflow）
  • 避免使用 position: absolute：频繁的绝对定位会导致重排

答案：

CSS 硬件加速是指利用 GPU 来渲染 CSS 动画，提高动画性能。通过使用 transform: translateZ(0)、transform: translate3d(0, 0, 0) 或 will-change: transform 等方式，可以触发浏览器的硬件加速。

面试示例回答 ​

问题：请解释 Flexbox 布局的工作原理 ​

回答：

Flexbox 是一种一维布局模型，它通过以下几个核心概念工作：

  1. 容器和项目：设置 display: flex 的元素是容器，它的直接子元素是项目
  2. 主轴和交叉轴：默认主轴是水平方向，交叉轴是垂直方向
  3. 空间分配：容器会根据项目的 flex 属性分配空间
  4. 对齐方式：可以通过 justify-content 控制主轴对齐，align-items 控制交叉轴对齐
  5. 弹性伸缩：项目可以根据容器空间自动伸缩

Flexbox 的优势在于它提供了一种简单、直观的方式来实现各种布局，特别是在处理不同屏幕尺寸的响应式布局时非常有用。

问题：如何实现一个流畅的 CSS 动画？ ​

回答：

要实现流畅的 CSS 动画，需要注意以下几点：

  1. 使用 transform 和 opacity：这两个属性不会触发重排，性能更好
  2. 避免使用 position: absolute：频繁的绝对定位会导致重排
  3. 使用 will-change：告诉浏览器元素将要发生变化，提前做好准备
  4. 控制动画时长：动画时长不宜过长或过短，一般在 0.3-0.6 秒之间
  5. 选择合适的缓动函数：根据动画效果选择合适的缓动函数
  6. 使用硬件加速：通过 transform: translateZ(0) 触发硬件加速
  7. 避免过多的同时动画：过多的动画会影响性能

通过这些优化措施，可以实现流畅、高性能的 CSS 动画效果。
