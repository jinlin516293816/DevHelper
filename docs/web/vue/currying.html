JavaScript 柯里化（Currying）详解 ​

1. 什么是柯里化 ​

柯里化（Currying）是一种函数转换技术，将一个接收多个参数的函数转换为一系列只接收单个参数的函数链。

简单来说，柯里化是将 f(a, b, c) 转换为 f(a)(b)(c) 的过程。

2. 基本实现 ​

手动实现柯里化 ​

javascript
// 普通函数
function add(a, b, c) {
  return a + b + c;
}

// 柯里化后的函数
function curriedAdd(a) {
  return function(b) {
    return function(c) {
      return a + b + c;
    };
  };
}

// 使用方式
console.log(add(1, 2, 3)); // 输出: 6
console.log(curriedAdd(1)(2)(3)); // 输出: 6

通用柯里化函数 ​

javascript
function curry(fn) {
  return function curried(...args) {
    // 如果参数数量足够，直接调用原函数
    if (args.length >= fn.length) {
      return fn.apply(this, args);
    }
    
    // 否则返回一个新函数，继续收集参数
    return function(...nextArgs) {
      return curried.apply(this, args.concat(nextArgs));
    };
  };
}

// 使用示例
const curriedAdd = curry(function(a, b, c) {
  return a + b + c;
});

console.log(curriedAdd(1)(2)(3)); // 输出: 6
console.log(curriedAdd(1, 2)(3)); // 输出: 6
console.log(curriedAdd(1)(2, 3)); // 输出: 6
console.log(curriedAdd(1, 2, 3)); // 输出: 6

3. 柯里化的应用场景 ​

3.1 参数复用 ​

javascript
// 计算商品折扣后的价格
function calculateDiscount(discount, price) {
  return price * discount;
}

// 柯里化
const curriedCalculateDiscount = curry(calculateDiscount);

// 创建一个 8 折计算器
const eightyPercentDiscount = curriedCalculateDiscount(0.8);

// 计算不同商品的折扣价格
console.log(eightyPercentDiscount(100)); // 输出: 80
console.log(eightyPercentDiscount(200)); // 输出: 160
console.log(eightyPercentDiscount(300)); // 输出: 240

// 创建一个 5 折计算器
const fiftyPercentDiscount = curriedCalculateDiscount(0.5);
console.log(fiftyPercentDiscount(100)); // 输出: 50

3.2 函数组合 ​

javascript
// 简单的函数组合
function compose(...fns) {
  return function(x) {
    return fns.reduceRight((acc, fn) => fn(acc), x);
  };
}

// 柯里化版本的函数组合
function curriedCompose(...fns) {
  return fns.reduce((a, b) => (...args) => a(b(...args)));
}

// 示例函数
const add = x => x + 1;
const multiply = x => x * 2;
const subtract = x => x - 3;

// 使用函数组合
const calculate = compose(subtract, multiply, add);
console.log(calculate(5)); // 输出: (5 + 1) * 2 - 3 = 9

// 使用柯里化的函数组合
const curriedCalculate = curriedCompose(subtract, multiply, add);
console.log(curriedCalculate(5)); // 输出: 9

4. 柯里化的优势 ​

  1. 参数复用：通过固定部分参数，创建新的函数
  2. 延迟执行：逐步收集参数，直到参数足够时才执行
  3. 函数组合：更方便地进行函数组合，构建复杂的函数
  4. 代码简洁：减少重复代码，提高代码可读性
  5. 类型推断：在TypeScript等静态类型语言中，有助于类型推断

5. 柯里化的局限性 ​

  1. 性能开销：每次柯里化都会创建新函数，有一定的性能开销
  2. 内存占用：柯里化函数会占用更多内存
  3. 代码可读性：对于不熟悉柯里化的开发者，可能会降低代码可读性
  4. 调试困难：柯里化函数的调用栈可能更复杂，增加调试难度

6. 高级应用 ​

6.1 自动柯里化 ​

javascript
// 自动柯里化函数
function autoCurry(fn) {
  return function curried(...args) {
    if (args.length >= fn.length) {
      return fn(...args);
    }
    
    return (...nextArgs) => curried(...args, ...nextArgs);
  };
}

// 使用示例
const add = autoCurry((a, b, c) => a + b + c);
console.log(add(1)(2)(3)); // 输出: 6

const multiply = autoCurry((a, b, c, d) => a * b * c * d);
console.log(multiply(2)(3)(4)(5)); // 输出: 120

6.2 部分应用（Partial Application） ​

部分应用与柯里化类似，但它是固定部分参数后立即返回一个新函数，而不是返回一系列函数。

javascript
// 部分应用函数
function partial(fn, ...fixedArgs) {
  return function(...remainingArgs) {
    return fn(...fixedArgs, ...remainingArgs);
  };
}

// 使用示例
function add(a, b, c) {
  return a + b + c;
}

const add5 = partial(add, 5);
console.log(add5(10, 15)); // 输出: 30

const add5And10 = partial(add, 5, 10);
console.log(add5And10(15)); // 输出: 30

7. 柯里化与其他函数式概念 ​

7.1 与闭包的关系 ​

柯里化依赖于闭包来存储已传入的参数。当我们创建一个柯里化函数时，它会形成一个闭包，保存之前传入的参数，直到所有参数都被收集完毕。

7.2 与纯函数的关系 ​

柯里化非常适合纯函数，因为纯函数没有副作用，相同的输入总是产生相同的输出。这使得柯里化函数更加可预测和易于测试。

7.3 与高阶函数的关系 ​

柯里化函数是高阶函数的一种，因为它接收一个函数并返回一个新函数。

8. 实际项目中的应用 ​

8.1 React 中的应用 ​

javascript
// React 中的柯里化示例
import React from 'react';

const Button = ({ onClick, children }) => (
  <button onClick={onClick}>{children}</button>
);

const App = () => {
  // 柯里化的事件处理函数
  const handleClick = (message) => (e) => {
    console.log(message);
    // 可以访问事件对象 e
  };

  return (
    <div>
      <Button onClick={handleClick('Hello')}>Say Hello</Button>
      <Button onClick={handleClick('World')}>Say World</Button>
    </div>
  );
};

9.2 柯里化与部分应用的区别 ​

  • 柯里化：将一个多参数函数转换为一系列单参数函数
  • 部分应用：固定部分参数，返回一个接受剩余参数的新函数

9.3 柯里化的优势 ​

  • 参数复用
  • 延迟执行
  • 函数组合
  • 代码简洁

10. 总结 ​

柯里化是一种强大的函数式编程技术，它可以帮助我们编写更简洁、更灵活的代码。通过将多参数函数转换为一系列单参数函数，我们可以实现参数复用、延迟执行和函数组合等功能。

虽然柯里化有一些性能开销，但在许多场景下，它带来的代码可读性和可维护性的提升是值得的。在现代 JavaScript 开发中，柯里化已经成为一种常见的编程模式，特别是在函数式编程风格的代码中。

通过掌握柯里化，我们可以写出更加优雅、高效的 JavaScript 代码，提高开发效率和代码质量。
