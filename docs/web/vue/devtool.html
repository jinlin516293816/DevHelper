DevTools性能面板分析 ​

问题：如何使用DevTools的Performance面板分析网页性能？ ​

答案：

1. 启动Performance录制：

F12打开DevTools → Performance面板
点击录制按钮（或按Ctrl+E）开始录制
进行页面操作后点击停止
1
2
3

2. 性能面板主要区域：

区域说明
概览FPS、CPU、NET三条曲线
火焰图Main线程、网络、GPU等
详情选中事件的详细信息
统计时间总和、任务分布

3. 关键指标分析：

javascript
// FPS（帧率）曲线
- 绿色正常（>60fps）
- 红色下降时出现卡顿
- 目标保持在60fps以上

// CPU曲线
- 高度表示CPU使用率
- 颜色对应不同类型任务（JS、渲染等）
- 过高说明有性能瓶颈

// NET（网络）区域
- 显示资源加载时间线
- 可找出加载慢的资源

内存泄漏查找 ​

问题：如何在DevTools中查找和定位内存泄漏？ ​

答案：

1. 内存泄漏常见场景：

javascript
// 1. 全局变量引用
const globalRef = []; // 全局变量累积

// 2. 事件监听器未移除
document.addEventListener('click', handler);
// 组件卸载前未removeEventListener

// 3. 闭包引用
function createClosure() {
  const data = largeObject;
  return function() {
    return data;
  };
}

// 4. 定时器未清理
setInterval(() => {}, 1000);
// 未clearInterval

// 5. 第三方库/插件内存泄漏
// 未正确调用清理函数

// 6. DOM元素引用
const elements = [];
elements.push(document.getElementById('el'));
// 元素删除后数组仍持有引用

性能优化实战 ​

问题：如何系统性地优化网页性能？ ​

答案：

1. 性能优化流程：

1. 性能测量（Lighthouse、Performance面板）
2. 定位瓶颈（Long Tasks、LCP、CLS等）
3. 制定优化方案
4. 实施优化
5. 重新测量验证
6. 持续监控
1
2
3
4
5
6

2. 性能优化常见手段：

类别优化方法
资源加载压缩、懒加载、预加载、CDN、缓存
JavaScript代码分割、Tree Shaking、异步加载、避免Long Tasks
CSS减少选择器复杂度、避免@import、内联关键CSS
图片响应式图片、WebP格式、适当压缩、懒加载
渲染避免强制同步布局、减少重排重绘、使用requestAnimationFrame
网络HTTP/2、预连接、减少请求数、压缩传输

3. 性能监控：

javascript
// RUM（真实用户监控）
// 使用工具如：
- Web Vitals 库
- Sentry Performance
- New Relic
- 自定义上报

// 关键指标监控
const observer = new PerformanceObserver(list => {
  list.getEntries().forEach(entry => {
    console.log(entry.name, entry.value);
  });
});
observer.observe({ entryTypes: ['largest-contentful-paint'] });
