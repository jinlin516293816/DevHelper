1. 数据类型 ​

问题：JavaScript 有哪些基本数据类型？ ​

答案：

JavaScript 有 7 种基本数据类型：

  1. Number：数字类型，包括整数和浮点数
  2. String：字符串类型
  3. Boolean：布尔类型，只有 true 和 false
  4. undefined：未定义，表示变量声明但未赋值
  5. null：空值，表示空对象引用
  6. Symbol：符号类型，表示唯一值
  7. BigInt：大整数类型，表示任意精度的整数

问题：如何判断数据类型？ ​

答案：

  1. typeof：判断基本数据类型（null 会返回 'object'）
  2. instanceof：判断引用类型
  3. Object.prototype.toString.call()：最准确的判断方法
  4. Array.isArray()：专门判断数组
javascript
typeof 123; // 'number'
typeof 'hello'; // 'string'
typeof true; // 'boolean'
typeof undefined; // 'undefined'
typeof null; // 'object' (注意：这是一个历史遗留问题)
typeof []; // 'object'
typeof {}; // 'object'
typeof function(){}; // 'function'

[] instanceof Array; // true
{} instanceof Object; // true

Object.prototype.toString.call(123); // '[object Number]'
Object.prototype.toString.call('hello'); // '[object String]'
Object.prototype.toString.call([]); // '[object Array]'
Object.prototype.toString.call({}); // '[object Object]'

Array.isArray([]); // true

3. 作用域与闭包 ​

问题：什么是作用域链？ ​

答案：

作用域链是 JavaScript 中用于查找变量的机制。当在当前作用域找不到变量时，会向上一层作用域查找，直到全局作用域。

javascript
var a = 1;
function fn1() {
  var b = 2;
  function fn2() {
    var c = 3;
    console.log(a + b + c); // 6
  }
  fn2();
}
fn1();

问题：什么是闭包？闭包的应用场景有哪些？ ​

答案：

闭包是指函数能够访问其外部作用域变量的特性，即使外部函数已经执行完毕。

应用场景：

  1. 私有变量

  4. 事件监听器
  5. 定时器

// 私有变量
function counter() {
  var count = 0;
  return {
    increment: function() {
      count++;
      return count;

    decrement: function() {
      count--;
      return count;
    }
  };
}

var c = counter();

4. this 关键字 ​

问题：this 的指向有哪些情况？ ​

答案：

  1. 全局环境：this 指向全局对象（浏览器中是 window，Node.js 中是 global）
  2. 函数调用：普通函数调用时，this 指向全局对象（严格模式下是 undefined）
  3. 对象方法：this 指向该对象
  4. 构造函数：this 指向新创建的实例对象
  5. call/apply/bind：this 指向指定的对象
  6. 箭头函数：this 指向外层作用域的 this（继承自外层）
javascript
// 全局环境
console.log(this); // window (浏览器)

// 函数调用
function fn() {
  console.log(this);
}
fn(); // window (非严格模式)

// 对象方法
var obj = {
  name: 'Alice',
  sayName: function() {
    console.log(this.name);
  }
};
obj.sayName(); // Alice

// 构造函数
function Person(name) {
  this.name = name;
}
var p = new Person('Bob');
console.log(p.name); // Bob

// call/apply/bind
function greet() {
  console.log('Hello, ' + this.name);
}
var person = { name: 'Charlie' };
greet.call(person); // Hello, Charlie

// 箭头函数
var obj2 = {
  name: 'David',
  sayName: function() {
    setTimeout(() => {
      console.log(this.name); // David
    }, 1000);
  }
};
obj2.sayName();

5. 原型与原型链 ​

问题：什么是原型链？ ​

答案：

原型链是 JavaScript 中实现继承的机制。每个对象都有一个原型对象（通过 proto 属性访问），原型对象又有自己的原型对象，这样层层递进就形成了原型链。

当访问对象的属性或方法时，如果对象本身没有，就会沿着原型链向上查找。

javascript
function Animal(name) {
  this.name = name;
}

Animal.prototype.sayName = function() {
  console.log('My name is ' + this.name);
};

function Dog(name, breed) {
  Animal.call(this, name);
  this.breed = breed;
}

Dog.prototype = Object.create(Animal.prototype);
Dog.prototype.constructor = Dog;

Dog.prototype.bark = function() {
  console.log('Woof!');
};

var dog = new Dog('Buddy', 'Golden Retriever');
dog.sayName(); // My name is Buddy
dog.bark(); // Woof!

  • prototype：函数对象特有的属性，指向该函数的原型对象（实例对象的 proto 指向该函数的 prototype）
javascript
function Person() {}
var p = new Person();

console.log(p.__proto__ === Person.prototype); // true
console.log(Person.prototype.__proto__ === Object.prototype); // true

问题：箭头函数与普通函数的区别是什么？ ​

答案：

  1. 语法更简洁：箭头函数可以使用简写语法

// 普通函数

// 箭头函数
const addArrow = (a, b) => a + b;

// this 绑定
const obj = {
  name: 'Alice',
  sayName: function() {
    setTimeout(() => {
      console.log(this.name); // Alice
    }, 1000);
  }

问题：Promise 的三种状态是什么？ ​

答案：

Promise 有三种状态：

  1. Pending：初始状态，既不是成功也不是失败
  2. Fulfilled：操作成功完成
  3. Rejected：操作失败

状态一旦改变，就不能再修改。

javascript
const promise = new Promise((resolve, reject) => {
  // 异步操作
  setTimeout(() => {
    if (Math.random() > 0.5) {
      resolve('Success!');
    } else {
      reject('Error!');
    }
  }, 1000);
});

promise
  .then(result => console.log(result))
  .catch(error => console.log(error));

7. 异步编程 ​

问题：什么是事件循环？ ​

答案：

事件循环是 JavaScript 中处理异步操作的机制。它包括以下几个部分：

  1. 调用栈：执行同步代码
  2. 任务队列：存放异步任务
  3. 微任务队列：存放 Promise 等微任务

执行顺序：

  1. 执行调用栈中的同步代码
  2. 执行微任务队列中的所有微任务
  3. 执行任务队列中的一个宏任务
  4. 重复步骤 2 和 3
javascript
console.log('1');

setTimeout(() => console.log('2'), 0);

Promise.resolve().then(() => console.log('3'));

console.log('4');

// 输出：1, 4, 3, 2

问题：async/await 和 Promise 的关系是什么？ ​

答案：

async/await 是基于 Promise 的语法糖，使异步代码看起来更像同步代码。

  • async 函数返回一个 Promise
  • await 只能在 async 函数中使用
  • await 后面跟着一个 Promise，等待 Promise 完成后才会继续执行
javascript
// 使用 Promise
function fetchData() {
  return fetch('https://api.example.com/data')
    .then(response => response.json())
    .then(data => data);
}

// 使用 async/await
async function fetchDataAsync() {
  const response = await fetch('https://api.example.com/data');
  const data = await response.json();
  return data;
}

1. 深拷贝与浅拷贝 ​

问题：如何实现深拷贝？ ​

答案：

  1. JSON.parse(JSON.stringify())：简单但有局限性（不能处理函数、正则、循环引用等）
  2. 递归拷贝：自己实现递归拷贝
  3. Lodash 的 cloneDeep：第三方库，功能完善
javascript
// JSON 方式
const obj1 = { a: 1, b: { c: 2 } };
const obj2 = JSON.parse(JSON.stringify(obj1));

// 递归实现
function deepClone(obj, hash = new WeakMap()) {
  if (obj === null || typeof obj !== 'object') return obj;
  if (obj instanceof Date) return new Date(obj);
  if (obj instanceof RegExp) return new RegExp(obj);
  if (hash.has(obj)) return hash.get(obj);
  
  const cloneObj = new obj.constructor();
  hash.set(obj, cloneObj);
  
  for (let key in obj) {
    if (obj.hasOwnProperty(key)) {
      cloneObj[key] = deepClone(obj[key], hash);
    }
  }
  
  return cloneObj;
}

2. 防抖与节流 ​

问题：什么是防抖和节流？如何实现？ ​

答案：

防抖（Debounce）：在事件被触发 n 秒后再执行回调，如果在这 n 秒内又被触发，则重新计时。

节流（Throttle）：规定在一个单位时间内，只能触发一次函数，如果这个单位时间内触发多次函数，只有一次生效。

javascript
// 防抖
function debounce(fn, delay = 300) {
  let timer = null;
  return function(...args) {
    clearTimeout(timer);
    timer = setTimeout(() => {
      fn.apply(this, args);
    }, delay);
  };
}

// 节流
function throttle(fn, delay = 300) {
  let last = 0;
  return function(...args) {
    const now = Date.now();
    if (now - last >= delay) {
      last = now;
      fn.apply(this, args);
    }
  };
}

3. 函数柯里化 ​

问题：什么是柯里化？如何实现？ ​

答案：

柯里化是把接受多个参数的函数变换成接受一个单一参数（最初函数的第一个参数）的函数，并且返回接受余下的参数而且返回结果的新函数的技术。

javascript
// 简单实现
function curry(fn) {
  return function curried(...args) {
    if (args.length >= fn.length) {
      return fn.apply(this, args);
    } else {
      return function(...args2) {
        return curried.apply(this, args.concat(args2));
      };
    }
  };
}

// 使用
function add(a, b, c) {
  return a + b + c;
}

const curriedAdd = curry(add);
curriedAdd(1)(2)(3); // 6
curriedAdd(1, 2)(3); // 6
curriedAdd(1, 2, 3); // 6

4. 实现继承的多种方式 ​

问题：JavaScript 中有哪些继承方式？ ​

答案：

  1. 原型链继承：通过构造函数的 prototype 实现
  2. 借用构造函数继承：在子类构造函数中调用父类构造函数
  3. 组合继承：原型链继承 + 借用构造函数继承
  4. 原型式继承：基于现有对象创建新对象
  5. 寄生式继承：原型式继承 + 增强对象
  6. 寄生组合式继承：组合继承的优化版
javascript
// 寄生组合式继承（最佳实践）
function object(o) {
  function F() {}
  F.prototype = o;
  return new F();
}

function inheritPrototype(subType, superType) {
  const prototype = object(superType.prototype);
  prototype.constructor = subType;
  subType.prototype = prototype;
}

function SuperType(name) {
  this.name = name;
}

SuperType.prototype.sayName = function() {
  console.log(this.name);
};

function SubType(name, age) {
  SuperType.call(this, name);
  this.age = age;
}

inheritPrototype(SubType, SuperType);

SubType.prototype.sayAge = function() {
  console.log(this.age);
};

5. 手写 Promise ​

问题：如何手写一个简单的 Promise？ ​

答案：

javascript
class MyPromise {
  constructor(executor) {
    this.state = 'pending';
    this.value = undefined;
    this.reason = undefined;
    this.onFulfilledCallbacks = [];
    this.onRejectedCallbacks = [];

    const resolve = (value) => {
      if (this.state === 'pending') {
        this.state = 'fulfilled';
        this.value = value;
        this.onFulfilledCallbacks.forEach(fn => fn(value));
      }
    };

    const reject = (reason) => {
      if (this.state === 'pending') {
        this.state = 'rejected';
        this.reason = reason;
        this.onRejectedCallbacks.forEach(fn => fn(reason));
      }
    };

    try {
      executor(resolve, reject);
    } catch (err) {
      reject(err);
    }
  }

  then(onFulfilled, onRejected) {
    onFulfilled = typeof onFulfilled === 'function' ? onFulfilled : value => value;
    onRejected = typeof onRejected === 'function' ? onRejected : reason => { throw reason };

    const promise2 = new MyPromise((resolve, reject) => {
      if (this.state === 'fulfilled') {
        setTimeout(() => {
          try {
            const x = onFulfilled(this.value);
            this.resolvePromise(promise2, x, resolve, reject);
          } catch (err) {
            reject(err);
          }
        }, 0);
      }

      if (this.state === 'rejected') {
        setTimeout(() => {
          try {
            const x = onRejected(this.reason);
            this.resolvePromise(promise2, x, resolve, reject);
          } catch (err) {
            reject(err);
          }
        }, 0);
      }

      if (this.state === 'pending') {
        this.onFulfilledCallbacks.push((value) => {
          setTimeout(() => {
            try {
              const x = onFulfilled(value);
              this.resolvePromise(promise2, x, resolve, reject);
            } catch (err) {
              reject(err);
            }
          }, 0);
        });

        this.onRejectedCallbacks.push((reason) => {
          setTimeout(() => {
            try {
              const x = onRejected(reason);
              this.resolvePromise(promise2, x, resolve, reject);
            } catch (err) {
              reject(err);
            }
          }, 0);
        });
      }
    });

    return promise2;
  }

  resolvePromise(promise2, x, resolve, reject) {
    if (promise2 === x) {
      return reject(new TypeError('Chaining cycle detected for promise'));
    }

    if (x !== null && (typeof x === 'object' || typeof x === 'function')) {
      let called = false;
      try {
        const then = x.then;
        if (typeof then === 'function') {
          then.call(
            x,
            y => {
              if (called) return;
              called = true;
              this.resolvePromise(promise2, y, resolve, reject);
            },
            r => {
              if (called) return;
              called = true;
              reject(r);
            }
          );
        } else {
          resolve(x);
        }
      } catch (err) {
        if (called) return;
        called = true;
        reject(err);
      }
    } else {
      resolve(x);
    }
  }

  catch(onRejected) {
    return this.then(null, onRejected);
  }

  static resolve(value) {
    return new MyPromise(resolve => resolve(value));
  }

  static reject(reason) {
    return new MyPromise((resolve, reject) => reject(reason));
  }
}

7. 内存管理与性能优化 ​

问题：如何避免内存泄漏？ ​

答案：

  1. 及时清理事件监听器
  2. 避免意外的全局变量
  3. 清理定时器
  4. 清理闭包引用
  5. 使用 WeakMap/WeakSet
  6. 避免循环引用
javascript
// 常见的内存泄漏
function createLeaks() {
  const element = document.getElementById('element');
  element.addEventListener('click', () => {
    console.log('Clicked!');
  });
  // 没有移除事件监听器
}

// 正确做法
function createNoLeaks() {
  const element = document.getElementById('element');
  const handleClick = () => {
    console.log('Clicked!');
  };
  element.addEventListener('click', handleClick);
  
  // 清理函数
  return () => {
    element.removeEventListener('click', handleClick);
  };
}

问题：请解释 JavaScript 的原型链 ​

回答：

JavaScript 的原型链是实现继承的核心机制。每个对象都有一个原型对象（通过 proto 属性访问），原型对象又有自己的原型对象，这样层层递进就形成了原型链。

当访问对象的属性或方法时，如果对象本身没有，就会沿着原型链向上查找，直到找到该属性或方法，或者到达 Object.prototype 为止。

原型链的优势在于可以实现代码复用和继承。通过原型链，子对象可以继承父对象的属性和方法，避免代码重复。

例如，Array 实例可以使用 push、pop 等方法，这些方法都定义在 Array.prototype 上，通过原型链可以被所有 Array 实例访问。

问题：请解释 Promise 的工作原理 ​

回答：

Promise 是 JavaScript 中处理异步操作的机制。它的工作原理基于以下几个核心概念：

  1. 状态：Promise 有三种状态：Pending（待处理）、Fulfilled（已完成）和 Rejected（已拒绝）。状态一旦改变，就不能再修改。
  2. 执行器函数：创建 Promise 时传入的函数，它接收 resolve 和 reject 两个参数，用于改变 Promise 的状态。
  3. 回调队列：当 Promise 的状态改变时，会执行相应的回调函数（通过 then 或 catch 注册的）。
  4. 链式调用：then 方法会返回一个新的 Promise，从而可以实现链式调用。

Promise 的优势在于它提供了一种优雅的方式来处理异步操作，避免了回调地狱，使代码更加清晰和可维护。

此外，Promise 还提供了静态方法，如 all、race、allSettled、any 等，用于处理多个 Promise 的情况。
