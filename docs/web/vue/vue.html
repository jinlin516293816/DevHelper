1. Vue的基本概念 ​

问题：什么是Vue？它有什么特点？ ​

答案：

Vue是一个用于构建用户界面的渐进式JavaScript框架，具有以下特点：

  • 渐进式：可以逐步引入，无需完全重写现有项目
  • 组件化：支持组件化开发，提高代码复用性
  • 响应式：数据变化自动更新视图
  • 单向数据流：遵循从父到子的数据流动
  • 虚拟DOM：通过虚拟DOM提高渲染性能

核心特点：

  • 简洁的模板语法
  • 强大的计算属性和侦听器
  • 完整的生命周期钩子
  • 丰富的指令系统
  • 易于集成第三方库

问题：Vue2和Vue3有什么区别？ ​

答案：

特性Vue2Vue3
响应式原理Object.definePropertyProxy
组件定义options APIcomposition API + options API
TypeScript支持较差完整支持
虚拟DOM普通虚拟DOM静态标记 + 完全不可变
打包大小较大减小约30%
生命周期beforeCreate/created等setup代替beforeCreate/created
API风格options API组合式API
多根节点不支持支持Fragment
Teleport不支持支持

new Vue({
  beforeCreate() {
    // 实例刚在内存中创建，data和methods都未初始化
    console.log('beforeCreate:', this.$data); // undefined
  },

  created() {
    // 实例已创建，data和methods已可用，但DOM未挂载

  beforeUpdate() {
    // 数据变化，DOM更新前
  },

  updated() {
    // DOM更新完成
  },

  beforeDestroy() {
    // 实例销毁前，清理定时器、事件监听等
  },

  destroyed() {
    // 实例已销毁
  }
})

4. 常用指令 ​

问题：v-if和v-show有什么区别？ ​

答案：

特性v-ifv-show
原理动态添加/删除DOM元素控制元素的display属性
编译过程条件块内的事件监听器和子组件会被销毁和重建只是切换元素的显示/隐藏
性能消耗切换时较高（创建/销毁）切换时较低（仅CSS切换）
初始渲染条件为false时不渲染初始会渲染（仅隐藏）
适用场景很少切换的条件频繁切换的条件
支持template支持不支持

示例：

html

<div v-if="show">内容1</div>
<div v-else>内容2</div>

<!-- v-show: 通过display:none控制显示 -->
<div v-show="show">内容</div>

3. 状态管理 ​

问题：Vuex的核心概念是什么？ ​

答案：

Vuex包含5个核心概念：

javascript
// 1. State - 单一状态树
state: {
  userInfo: null,
  count: 0,
  todos: []
}

// 2. Getter - 像是store的计算属性
getters: {
  doubleCount: state => state.count * 2,
  activeTodos: state => state.todos.filter(t => !t.completed),
  getTodoById: (state) => (id) => {
    return state.todos.find(t => t.id === id);
  }
}

// 3. Mutation - 更改状态的唯一方法（同步）
mutations: {
  INCREMENT(state, payload) {
    state.count += payload.amount;
  },
  SET_USER(state, user) {
    state.userInfo = user;
  }
}

// 4. Action - 提交mutation，可以包含异步操作
actions: {
  async fetchUser({ commit }, userId) {
    const user = await api.getUser(userId);
    commit('SET_USER', user);
  },
  incrementAsync({ commit }) {
    setTimeout(() => {
      commit('INCREMENT', { amount: 1 });
    }, 1000);
  }
}

// 5. Module - 模块化管理store
modules: {
  user: {
    namespaced: true,
    state: () => ({ name: '张三' }),
    mutations: {
      setName(state, name) { state.name = name; }
    },
    actions: {
      async fetchName({ commit }) { /* ... */ }
    },
    getters: {
      upperName: state => state.name.toUpperCase()
    }
  }
}

app.config.globalProperties.$formatPrice = (price) => {

  formatPrice

1. 响应式原理 ​

问题：Vue 3的响应式系统是如何工作的？ ​

答案：

Vue 3使用Proxy和Reflect实现响应式：

核心实现：

javascript
// 依赖收集 - track函数
function track(target, key) {
  if (activeEffect) {
    const depsMap = targetMap.get(target);
    if (!depsMap) {
      targetMap.set(target, (depsMap = new Map()));
    }
    const dep = depsMap.get(key);
    if (!dep) {
      depsMap.set(key, (dep = new Set()));
    }
    dep.add(activeEffect);
    activeEffect.deps.push(dep);
  }
}

// 触发更新 - trigger函数
function trigger(target, key) {
  const depsMap = targetMap.get(target);
  if (!depsMap) return;

  const dep = depsMap.get(key);
  if (dep) {
    dep.forEach(effect => effect());
  }
}

// 创建响应式对象
function reactive(target) {
  return new Proxy(target, {
    get(target, key, receiver) {
      track(target, key);
      return Reflect.get(target, key, receiver);
    },
    set(target, key, value, receiver) {
      const oldValue = target[key];
      const result = Reflect.set(target, key, value, receiver);
      if (oldValue !== value) {
        trigger(target, key);
      }
      return result;
    },
    deleteProperty(target, key) {
      const oldValue = target[key];
      const result = Reflect.deleteProperty(target, key);
      if (result) {
        trigger(target, key);
      }
      return result;
    }
  });
}

function render(vnode, container) {
  // 创建真实DOM
  const el = document.createElement(vnode.type);

  // 设置属性
  Object.keys(vnode.props).forEach(key => {
    if (key.startsWith('on')) {
      el.addEventListener(key.slice(2).toLowerCase(), vnode.props[key]);
    } else {
      el.setAttribute(key, vnode.props[key]);
    }
  });

  // 递归创建子节点
  if (Array.isArray(vnode.children)) {
    vnode.children.forEach(child => {
      el.appendChild(render(child, el));
    });
  } else {
    el.textContent = vnode.children;
  }

  vnode.el = el;
  container.appendChild(el);
}

3. nextTick原理 ​

问题：nextTick的实现原理是什么？ ​

答案：

nextTick用于在DOM更新后获取最新的状态：

javascript
let pending = false;
const callbacks = [];

function flushCallbacks() {
  pending = false;
  const copies = callbacks.slice(0);
  callbacks.length = 0;
  copies.forEach(callback => callback());
}

function nextTick(callback) {
  callbacks.push(callback);
  if (!pending) {
    pending = true;
    if (typeof Promise !== 'undefined') {
      Promise.resolve().then(flushCallbacks);
    } else if (typeof MutationObserver !== 'undefined') {
      const observer = new MutationObserver(flushCallbacks);
      observer.observe(document.createTextNode(''), { characterData: true });
      observer.disconnect();
    } else {
      setTimeout(flushCallbacks, 0);
    }
  }
}

// 使用微任务确保在DOM更新后执行
async function update() {
  state.message = 'updated';
  await nextTick();
  // 此时DOM已更新
  console.log(document.querySelector('.content').textContent);
}

问题：Vue是如何实现数据驱动视图的？ ​

答案：

Vue的数据驱动视图是通过响应式系统、虚拟DOM和patch过程实现的：

核心流程：

数据变化（响应式）
     ↓
触发set拦截器
     ↓
调用trigger函数
     ↓
从targetMap找到对应的effect
     ↓
将effect放入微任务队列
     ↓
微任务执行effect
     ↓
触发组件更新（updated）
     ↓
执行render函数生成新的vnode
     ↓
进行diff比较
     ↓
最小化更新真实DOM
     ↓
视图更新完成
