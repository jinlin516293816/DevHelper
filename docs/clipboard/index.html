核心功能

📋 剪贴板历史管理

  • 全面支持：文本、图片等多种内容类型
  • 大容量存储：最多可保存200条历史记录
  • 智能固定：重要记录固定保存，防止被覆盖
  • 快速搜索：强大的搜索功能，瞬间定位所需内容

⌨️ 高效快捷键系统

  • Alt+W：一键呼出剪贴板管理器面板
  • Alt+(1-5)：直接输入最近5条历史记录
  • 智能过滤：快捷输入自动排除固定记录
  • 自定义设置：支持修改快捷输入修饰键

📝 灵活内容操作

  • 详情预览：文本内容点击查看完整详情
  • 便捷操作：支持复制、删除、修改历史记录
  • 批量管理：一键清空所有历史记录
  • 智能输入：C++模拟输入，避免输入法闪烁

🔒 数据安全保障

  • 本地存储：所有数据仅保存在您的设备上
  • 隐私保护：不收集、不上传任何用户数据
  • 安全访问：严格的本地权限控制，防止数据泄露
  • 数据加密：可选的剪贴板内容加密功能
